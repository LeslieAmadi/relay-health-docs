# Build and tooling notes

Problems hit while building this site, and how they were resolved.

## Stale plugin cache after deleting docs
Deleting scaffold files while the dev server was running produced 36
module-resolution errors against `@site/docs/...`. The files were gone but the
content plugin still held their route entries. Fixed with `npm run clear` to
remove `.docusaurus` and the bundler cache, then restarting.

## Empty docs directory
`Docs version "current" has no docs!` — the docs plugin requires at least one
document. Expected after clearing the scaffold; resolved by creating the
Diátaxis structure.

## Config changes appearing not to apply
The site kept rendering the default title and an autogenerated sidebar after
editing the config. The files had been edited but not saved. Diagnosed with
`grep -n "title:" docusaurus.config.js` — checking what is on disk rather than
what is in the editor.

## Deprecated config option
The build warned that `onBrokenMarkdownLinks` moves to `markdown.hooks` in
Docusaurus v4. Migrated proactively rather than waiting for v4 to break the
build.

## Broken internal link
With `onBrokenLinks: 'throw'`, a link to a non-existent page fails the
production build. The dev server tolerates it; `npm run build` does not.
This is the mechanism that stops link rot reaching readers.
